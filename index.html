02 / TENTANG SAYA

Pendekatan & Perangkat

Ketertarikan Saya pada pengembangan web dimulai dari rasa penasaran bagaimana sebuah situs bisa terasa begitu nyaman saat digunakan. Saya percaya desain yang baik tidak butuh hiasan rumit, melainkan kejelasan fungsi dan detail yang rapi.

Saat ini saya banyak bekerja dengan ekosistem modern JavaScript maupun membangun halaman statis yang ringan, sambil terus mendalami arsitektur aplikasi full-stack.

Teknologi yang Sering Digunakan

Frontend

HTML5, CSS3, JavaScript (ES6+), TypeScript, React, Next.js, Tailwind CSS

Backend & Data

Node.js, Prisma ORM, SQLite, REST API

Alat Kerja

Git, GitHub, VS Code, Figma

Fokus & Kompetensi

Pengembangan Antarmuka & Tata Letak

Merancang navigasi yang intuitif, optimasi proporsi tampilan publik, serta penyesuaian desain responsif di berbagai ukuran layar.

Sistem Manajemen Konten (Admin Panel)

Membangun fitur pengaturan situs dinamis, pengelolaan tautan/data organisasi, dan integrasi formulir dengan database.

Pengolahan Data & Dokumentasi

Menyusun struktur dokumen laporan, otomatisasi rumus spreadsheet, serta visualisasi data tabel yang rapi dan terukur.
